# Demo dataset

The demo workspace is generated by `apps/api/app/scripts/seed_demo.py`. It creates 11 vendors,
20 purchase orders, 103 invoices, real PDF documents (invoices and contracts), 140+ exceptions,
30 cases, approvals and workflow history. Every row is marked `is_demo=true` where the schema
supports it.

- `vendors_sample.csv` is a small, fictional import file that demonstrates the CSV integration
  path. It is safe to import into the demo organization.
- `../evaluation/investigation_samples.json` is the labelled synthetic set used by the AI
  evaluation lab.

Reset and reseed at any time:

```bash
cd apps/api
python -m app.scripts.reset_demo --yes --seed
```
